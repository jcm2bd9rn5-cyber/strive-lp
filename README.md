# Strive LP

**Strive - Workout Tracking App のランディングページ**

筋トレ記録と継続支援に特化した iOS アプリ「Strive」のランディングページです。

---

## 🎯 概要

Strive は以下の特徴を持つ筋トレ記録アプリです：

- 🏋️ **素早い記録** - トレーニング中でもサクサク記録できる UI
- 📊 **進捗管理** - 前回の重量・回数、PR、月間レポート
- 👥 **ソーシャル機能** - フレンド機能、ランキング
- 🎫 **サブスクリプション** - プレミアム機能で完全体験
- ⏱️ **インターバルタイマー** - 効率的なトレーニング支援
